# Portfolio

Personal portfolio of Seifeddine Ben Salah, Full Stack Software Engineer.

English: https://seifeddinebs.github.io/myportfolio/en/
German: https://seifeddinebs.github.io/myportfolio/de/

The root URL redirects to German for German browsers and to English otherwise.

Plain HTML, CSS and JavaScript with no build step. Open `en/index.html` or `de/index.html` in a browser to preview. Text changes have to be made in both files. GitHub Pages serves the `main` branch.
