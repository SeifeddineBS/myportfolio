02 · Working with AI

AI agents write with me. I stay responsible for what ships.

AI coding agents are part of my daily workflow, not an experiment. They make me faster on implementation, debugging and tests. The engineering judgment stays with me.

A

Agentic coding

I work with Claude Code agents on real production codebases: implementing features, tracing bugs across frontend and backend, and refactoring.

B

Context engineering

Good output needs good input. I give agents the project context, conventions and constraints they need, and write prompts that describe the goal clearly.

C

AI-assisted testing

I use agents to generate tests and to check changes in a real browser with Playwright, so regressions show up before a release.

D

Human review

Nothing goes live unread. I review and validate every generated change, the same way I would review a colleague's pull request.
